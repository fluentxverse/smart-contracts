# Integration Boundary

The application integration lives in the FluentXVerse application and Engine
repositories; this repository contains the contracts and their local tests.

See [deployment status](dispute-mainnet-production.md) for the November 3, 2026
activation record. The contract README documents required permissions, canonical
evidence commitments, deadline reconciliation, and exactly-once refund delivery.
Those checks depend on off-chain services and cannot be established by Solidity
unit tests alone. No production service configuration or private evidence is published here.
