# Retired Contracts

These implementations were retired from the application on October 19, 2026 and
are preserved unchanged for historical reference:

- `AnonymousReviewRegistry.sol`
- `TutorScreeningValidator.sol`
- `LessonPassLedger.sol`

They are not dependencies of the current dispute contract, are not covered by its
test suite, and must not be deployed or reactivated based on their presence here.
Their Solidity version and integration assumptions differ from the current project.
No legacy private keys, scripts, application data, or runtime configuration are included.
